# Craigslist Used Car Price Prediction

This project uses machine learning to predict the prices of used cars listed on Craigslist, helping buyers and sellers make informed decisions.

## 💡 Project Overview

- Predict used car prices using features like year, odometer, condition, manufacturer, and type.
- Built with RandomForestRegressor, achieving an R² score of 0.82 and MAE of ~$2,685.
- Includes EDA, feature engineering, model building, and evaluation.
